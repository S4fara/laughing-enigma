# Плеер (PWA)

React + TypeScript + Vite. Музыка хранится в IndexedDB на устройстве, работает оффлайн.

## Запуск на ПК
```
npm install
npm run dev
```
Откройте http://localhost:5173.

## Установка на iPhone
iPhone требует HTTPS, поэтому приложение нужно выложить в сеть (бесплатно):
1. Создайте репозиторий на GitHub и загрузите проект в ветку `main`.
2. Settings → Pages → Source: **GitHub Actions**.
3. После сборки откройте ссылку `https://<логин>.github.io/<репозиторий>/` в **Safari** на iPhone.
4. «Поделиться» → «На экран «Домой»». Запускайте с иконки, не из Safari.
